# T-Rex + Mosasaurus Mod (Fabric, Minecraft Java 26.3)

## Build
JDK 25 + Gradle  ->  gradle build  (หรือใช้ GitHub Actions ใน .github/workflows/build.yml)

## T-Rex (บนบก)
- เกิดในป่า / ป่าดิบชื้น / ซาวันนา / ไทกา (หายาก)
- ตัวป่าไล่ผู้เล่นและสัตว์ มีท่าคำรามเงยหน้า อ้าปากกว้าง ตัวสั่น + ท่ากัด + ท่านั่ง
- จับ: ถือปลาแซลมอนดิบคลิกขวา 25%/ตัว (พลาดอาจโดนกัด)

## Mosasaurus (ในทะเลลึก)
- เกิดในมหาสมุทรลึก ล่าสัตว์น้ำและผู้เล่นที่ลงน้ำ/นั่งเรือ
- ท่าว่ายหางส่ายเป็นคลื่น ครีบพาย เอียงตัวตามทิศ ท่าคำราม ท่างับ ท่าดิ้นเมื่อขึ้นบก
- จับ: ถือปลาคอดดิบคลิกขวา 20%/ตัว (พลาดมี 50% ที่จะโกรธแล้วงับ)
- เชื่องแล้ว: ว่ายตามเจ้าของ ปกป้องจากมอนสเตอร์ ป้อนปลาคอดเพื่อรักษา มือเปล่า = สั่งอยู่เฉยๆ/ตามมา
